# Kanal Otomasyonu

**[Privacy Policy](PRIVACY.md) · [Terms of Use](TERMS.md)**

Kanal Otomasyonu is a private, internal tool used by a single YouTube creator to manage their own YouTube channels. It runs only on the owner's own Android phone. It is not offered, distributed or sold to anyone else, and it has no other users.

The tool uses **YouTube API Services**. By using it, users agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). See also the [Google Privacy Policy](https://policies.google.com/privacy).

## What it does

The owner produces original videos (map-based documentaries, short educational videos and study-timer videos). After the owner reviews and approves a specific video, the tool uses the YouTube API Services to:

- upload the video to the owner's own channel and set its title, description, tags, category, language and audience (made-for-kids) setting,
- set the custom thumbnail, upload subtitles and add the video to a playlist,
- schedule the publish time,
- update the owner's channel branding (description, keywords, banner image),
- read the owner's own channel analytics (views, watch time, traffic sources, average view percentage) to plan future videos.

Nothing is uploaded or changed without the owner's approval.
